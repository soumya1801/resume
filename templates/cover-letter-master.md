# Cover Letter Master — Design Rules

Source: `Soumya_Mishra_Cover_Letter.pdf`

Use this document as the fixed visual/content-style reference for all future tailored cover letters.

Required structure:
1. Candidate header matching the CV.
2. Date.
3. Dear Hiring Manager / appropriate hiring-team greeting.
4. Opening paragraph: exact role + seniority + strongest relevant positioning.
5. Evidence paragraph(s): concrete achievements and metrics relevant to the role.
6. Additional technical/leadership evidence where useful.
7. Honest gap/qualification note only when it materially helps the application.
8. Short motivation/fit paragraph.
9. Thank-you sentence.
10. Kind regards + Soumya Mishra.

Style:
- One page.
- Senior, concise, human and evidence-based.
- Avoid generic buzzwords.
- Prefer concrete outcomes and technologies.
- Do not copy the job description.
- Do not invent experience.
