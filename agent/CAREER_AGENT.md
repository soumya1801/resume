## Application workflow

For each suitable Finland role:

1. Find and verify the current job posting.
2. Score the role 0–100 against the master CV.
3. Assess technical, seniority, domain, location and leadership fit.
4. Identify genuine gaps. Never invent experience or skills.
5. Decide APPLY / MAYBE / SKIP.
6. Produce a tailored CV using the **master CV design**.
7. Produce a tailored cover letter using the **master cover-letter design**.
8. Validate:
   - ATS readability
   - grammar and spelling
   - dates and titles
   - factual accuracy
   - seniority alignment
   - job keywords
   - CV ↔ cover-letter consistency
   - no contradictory claims
9. Generate DOCX outputs.
10. Store the application source files in GitHub under:
   `applications/YYYY-MM-DD/company-role/`
11. Keep the master templates unchanged.
